Design direction

Control Room HUD

A traffic-operations-centre screen: near-black navy on a faint grid, 1 px line work, corner brackets and monospace telemetry. It is dense but calm. Red, yellow and green exist only as light: on the live screen a glow always means a live signal aspect (a lit lamp in a vertical head, a stop bar, a state word). The brand's R→Y→G appears only as a flat horizontal triad hairline or the loader. System health uses square pips and alerts use a rose triangle tag. When data goes stale the glow switches off and the lens turns hatched, so “not live” reads at a glance.

  • Signal aspectGlowing lens in a vertical head, stop bar, state word. Always labeled.
  • System statusFlat square pip + word: links, flood, fault.
  • AlertRose triangle tag (breach, link lost). Never a lens.
  • DecorationHorizontal R·Y·G triad, flat, 40%, never one hue alone.
